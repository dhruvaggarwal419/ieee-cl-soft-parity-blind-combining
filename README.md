# Blind frame combining from a soft parity-check statistic

Authors: Dhruv Aggarwal, Mohd. Rehan Ghazi, Ajay Kaushik.

`code/` simulation code (`lib.py` statistic and decoders, `exp*.py` experiments, `code/extension_runs/` further studies). `data/` saved results (JSON) for operating range, complexity, exact moments, code family, baselines, channels, ratio search and normalisation; `results_original/` earlier results.

Requirements: Python 3.11 with numpy, scipy, torch and matplotlib. Random seeds are fixed in the scripts. Large arrays are regenerated by the code and are not stored.
